# 项目工作区下一版优化计划

日期：2026-11-04

状态：第一批已实施并通过相关验收；第二、三批保留为后续阶段。用户补充的左侧项目导航去重已纳入第一批。

## 目标

让用户进入项目后能看懂当前目录，方便找到文件，连续浏览并围绕文件开展对话。优先解决用户已经遇到的“文件夹没展示”，再补充效率功能。

现有项目归属、目录绑定、历史产物路径、文件树、只读预览和项目内对话沿用当前实现。

## 已确认的体验与实现缺口

| 优先级 | 当前情况                                                                   | 优化结果                                                 |
| ------ | -------------------------------------------------------------------------- | -------------------------------------------------------- |
| P0     | 默认工作区和绑定目录为空都显示“此文件夹为空”；换目录入口藏在项目设置       | 文件区显示目录来源、实际路径和直接选择/更换目录操作      |
| P0     | 可用宽度不足 780px 时，默认项目面板覆盖正文；只有文件/产物预览出现关闭按钮 | 右侧统一可收起、恢复，窄屏通过抽屉访问，关闭后回到原位置 |
| P1     | 文件区位于项目资料内部，限高 288px；预览会替换目录导航                     | 文件成为右侧直接入口，预览可快速返回原目录并连续切换文件 |
| P1     | 外部文件变化只在手动刷新或重新挂载后反映                                   | 返回应用时自动刷新可见目录和当前预览，保留手动刷新       |
| P1     | 预览只有刷新和在文件夹中显示，缺少对话引用                                 | 从文件树/预览直接将项目文件加入当前输入框，发送前可移除  |
| P1     | 产物列表逐项同步读取，某项读取失败可能导致整个查询失败                     | 按条目展示丢失/不可读状态，其他产物保持可用              |

窄屏覆盖、错误隔离和重复请求结论来自代码检查，尚未在本轮重新执行运行时复现。大量文件导致卡顿属于需要测量的风险。

## 第一批：目录入口、布局和可靠性

### 0. 左侧项目导航去重

- 合并「所有项目」、项目分组与底部「全部项目」为一个项目分组。分组标题进入总览，旁边加号负责创建，下方列最近项目和会话。
- 收起侧栏时仅保留一个项目总览图标，避免一列无名称的重复文件夹图标。
- 全局会话、产物和其他能力入口保持可访问；命令搜索仍可找到项目总览。

### 1. 目录状态直接展示

- 文件区顶部始终显示目录名；完整路径可以查看和复制。
- 未选择本地目录时显示“使用默认共享工作区”，说明多个未绑定项目使用同一目录，同时提供“选择本地文件夹”。默认工作区有文件时继续正常展示。
- 已绑定空目录显示具体目录和空态，不提示成未绑定。
- 目录不可用时保留路径，提供“重试”和“更换文件夹”；切换目录不会搬移已有文件。
- 原生选择完成后调用现有项目保存接口，立即刷新文件树；取消保持原值。后续运行继续遵循现有目录快照规则。

### 2. 右侧工作区调整

- 右侧提供“文件 / 产物 / 浏览器”直接入口；项目简介改为可折叠信息，项目设置保留在现有设置入口。
- 文件树使用剩余高度，减少外层与文件区双重滚动。
- 所有右侧模式共享收起按钮和恢复入口；宽屏支持拖动宽度并记住设置，保证中央输入区的最小宽度。
- 窄屏默认不覆盖中央对话，主动打开时使用可关闭抽屉，支持 Escape、关闭后焦点恢复。
- 第一批预览增加“返回文件”、路径面包屑及同目录上一项/下一项；返回时恢复展开状态、选中项和滚动位置。
- 原有预览深链接、前进后退、浏览器状态仍需通过回归验证。

### 3. 文件刷新与产物错误隔离

- 窗口重新获得焦点时合并刷新可见目录和当前预览，避免递归扫描整个项目。
- 合并一次产物操作引发的重复刷新，按项目/目录更新相关视图，忽略旧请求结果。
- 被删除的文件清楚提示失效，预览不继续显示旧内容；权限恢复后可重试。
- 产物查询逐项处理读取失败；使用当前文件信息判断大小，并限制读取量，不依赖数据库中的旧大小。
- 项目单条信息查询与全部项目汇总拆开，减少浏览目录时的重复汇总工作；用大目录样本测量效果。

## 第二批：围绕文件开展对话

### 4. 文件引用

- 文件菜单和预览增加“添加到对话”“复制相对路径”。项目首页加入新对话草稿，聊天页面加入当前会话草稿。
- 输入框显示可移除的文件标签，明确文件名称和项目内路径。
- 项目本地文件使用独立的引用结构，携带项目、目录版本/身份与相对路径；发送时重新校验目录边界和可读性，再转换为 Agent 可访问的工作区路径。
- 浏览行为不自动读取文件正文加入模型上下文；实际发送时明确引用。目录已改变或文件已消失时要求重新选择，避免相同路径被默默指向另一份文件。
- 草稿文字和文件引用按项目/会话保存，切换页面不带入其他项目；现有上传附件的作用域同时检查。

### 5. 搜索与大目录

- 首版搜索文件名和相对路径，显示匹配路径，并可定位到文件树。
- 搜索请求可取消、忽略过期结果，说明隐藏文件是否包含在结果中。
- 单层列表支持分页或加载更多，确保第 501 项及后续条目可以访问。
- 继续保留懒加载和目录范围校验；增加缓存容量控制及项目删除后的清理。
- 外部变化自动监听作为后续增强，先根据聚焦刷新和性能测量决定监听范围与排除规则。

## 第三批：项目首页的继续工作入口

- 保留当前底部输入框和最近对话。
- 增加少量最近打开文件、最近产物入口；显示来源及更新时间。
- 打开后恢复对应项目、文件位置或对话；失效记录提供移除/重新定位。
- 长期项目较多时再增加固定项目、会话归档和最近活动筛选。

## 验收清单

1. 无绑定目录的新项目，从右侧直接选择临时目录，保存后立即出现文件树；取消选择不改变项目。
2. 默认工作区有文件、已绑定空目录、目录不存在、无权限分别显示准确状态，并有可用操作。
3. 1600×1000、1024×760、800×600 与浅深色下，中央输入区可访问；右侧均能收起和恢复，抽屉关闭后焦点正确。
4. 展开多层目录、滚动并打开文件，返回后位置不丢失；连续预览文件、刷新和前进后退正常。
5. 在临时目录外部新增、编辑、重命名、删除文件，返回应用后可见内容更新，无跨项目旧内容。
6. 单个产物丢失或不可读时其他产物可浏览和导出；文件在外部变大时不触发无上限整文件读取。
7. 添加文件引用后切换项目或会话，草稿作用域正确；文件消失或目录改变时不会读到错误文件。
8. 超过 500 项的目录可以找到并打开后续文件；搜索、刷新和切换目录的乱序响应不污染当前视图。
9. 回归已有目录快照、历史产物、删除项目保留文件、移动会话、未归属对话和 `outputs.*` 兼容行为。
10. 分批运行 typecheck、lint、format:check、i18n、单测、构建及相关 E2E，保留实际结果。上一轮全量巡检的五组未通过仍须独立跟踪，不能据此宣称全量全绿。
