## 实现范围

- 左侧项目导航去重：总览入口合并到项目分组标题，保留新建与最近项目/会话；收起后只有一个项目图标。

- 聚焦应用时刷新可见文件；刷新事件合并，忽略迟到请求。
- 单个产物丢失/不可读不影响其他产物，使用实际大小和有界读取；项目详情按 ID 查询，文件浏览避免全项目汇总。
