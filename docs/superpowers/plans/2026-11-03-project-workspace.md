# Navo 项目工作区第一版实施计划

日期：2026-11-03 · 状态：第一版与三栏布局优化已完成，相关验收通过；全量巡检另有 5 组未通过。

## 目标与现状

把项目升级为可进入、可继续工作的工作区，打通「项目侧栏 → 项目详情 → 对话 → 产物预览 → 来源会话」。

现有工作区已经包含项目表、可选会话归属、项目 CRUD、Artifacts 聚合 API 和基础管理页面；本轮在此基础上完成项目详情、路由联动、统一预览和真实交互回归。

设计参考用户提供的 Codex 三栏截图，以项目组织会话和产物，在 Navo 中实现左侧项目导航、中间工作内容、右侧项目资料及产物预览。

## 页面与交互

### 项目侧栏与总览

- 侧栏直接列出项目，可展开最近会话；点击项目名称进入项目详情。
- 保留全部会话、全部产物和所有项目入口。任务、能力、设置沿用现有导航。
- 项目总览支持搜索，显示描述、最近活动、会话与产物数量。整行可点击，编辑、删除放入更多菜单。
- 项目按最近活动排序，侧栏展开状态在本机保存。

### 项目详情

- 默认显示对话页签；另外提供 Artifacts 和项目设置页签。
- 按后续参考图优化：空项目显示居中欢迎区，输入框固定在中间工作区底部并显示项目标签；已有会话时列表独立滚动，切换页签保留输入草稿。
- 顶部固定紧凑标题、描述、会话与产物数量以及新建对话操作，正文独立滚动。
- 按用户补充的三栏参考优化：左侧项目导航，中间工作内容，右侧默认显示项目资料与可点击产物列表；右侧可切换浏览器和文件预览。
- 可直接在详情页输入任务；发送后创建明确归属该项目的对话并进入聊天。
- 历史会话显示标题、更新时间、运行中、等待确认和失败等状态，点击可继续。
- 切换项目只改变展示，不停止或重置其他会话的运行。

### 项目内对话

- 复用现有聊天、审批与消息逻辑，保留项目面包屑和返回项目入口。
- 支持将已有会话移动到另一项目或取消归属，移动后同步当前路由与列表。
- 项目内新建传入明确项目 ID；全局入口创建未归属对话，不依赖上次筛选的值。
- 项目名称和描述作为每轮运行的背景信息，不自动拼接其他会话的消息。

### Artifacts 与预览

- 项目内只展示本项目产物；全局入口展示全部及未归属产物。
- 支持文件名搜索、类型筛选、预览、导出、另存和打开。
- 每项显示来源会话，提供打开来源会话操作；聊天中的产物入口复用同一套预览。
- 宽屏使用右侧预览栏，窄屏使用全宽预览，返回后恢复列表位置。
- 产物预览与已有浏览器面板共用右侧空间，以标签切换，避免同时压缩聊天区。

### 项目设置与删除

- 编辑项目名称和描述，保存后用于后续运行。
- 删除时说明：对话和产物保留，转为未归属。
- 当前项目被删除后返回项目总览，其他窗口收到删除更新时也清理失效筛选。
- 无项目时始终可以正常新建和继续对话。

## 实现约定

- 增加 `/projects/:projectId`、`/projects/:projectId/chat/:threadId` 和 `/chat/:threadId` 路由；现有 `/projects`、`/artifacts`、`/chat` 入口保留。
- 页签与选中产物放入 URL 查询参数，支持刷新、直接打开、前进和后退；项目与会话身份以路由和实际归属为准。
- 补充项目详情查询，返回项目资料与汇总信息；保留现有 `outputs.*` 兼容接口。
- 抽取共享会话列表、产物列表与产物预览，避免复制全局页面与项目页面逻辑。
- `useChat` 继续按会话 ID 保存消息、运行及中断状态；项目导航不清空这些状态。
- Artifacts 按查询范围管理缓存，忽略过期请求。切换范围后加载失败必须显示错误，不能在新项目标题下显示旧项目数据。
- 删除、重命名或移动项目及会话后，同步更新侧栏、详情、产物元信息和当前路由。
- 产物写入、导出和下载时记录来源会话，替代仅按运行时间扫描共享目录来判断归属，防止并行运行时误归类。
- 按用户补充需求，新建和编辑项目可选择本地工作目录；不选则使用默认工作区。`/workspace/` 挂载到本轮目录快照，目录切换不移动旧文件，历史产物保存原目录位置；审批恢复也沿用暂停时的目录。任务、上传文件、记忆和 Skill 继续使用现有全局能力。
- 保留当前工作区的其他未提交修改，不重置、不覆盖。

## 验收标准

- 创建、编辑项目后能进入详情；名称和描述刷新后仍保留。
- 从项目详情创建对话归属正确；从全局创建对话保持未归属。
- 两个项目中的会话同时运行，切换后运行状态、审批状态与产物归属正确。
- 项目产物可搜索、筛选、预览及导出，并能打开来源会话。
- 移动会话后，其产物聚合和当前页面同步到新归属。
- 删除正在查看或筛选的项目后，对话和文件仍可访问，也能继续创建未归属对话。
- 直接打开详情、会话及预览链接，刷新与前进后退后仍处于正确位置。
- 模拟加载失败和请求乱序，不出现跨项目旧数据；文件缺失有明确反馈。
- 在窄屏及浏览器面板展开时检查预览、按钮与正文，确保可操作。
- 验证旧库升级和旧 `outputs.*` 调用兼容。
- 运行类型检查、lint、格式检查、i18n、单测和相关 E2E；全量 E2E 单独记录未通过或未执行的场景。
