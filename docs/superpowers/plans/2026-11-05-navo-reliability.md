# Navo 整体体验与可靠性优化

日期：2026-11-05。实现分支：`codex/navo-reliability-experience`。

## 已实施的四批功能

### 草稿、可靠接收与任务生命周期

- SQLite 持久草稿按主窗口/快问及会话/项目/新对话隔离，保留文本、附件、文件引用与模型选择。短防抖写入、切页/失焦刷新、关闭前同步保存；保存失败阻止正常关闭。
- 草稿版本和编辑代次防止迟到保存、清空及迁移覆盖新输入。主窗口接收快问迁移前先保存自己的草稿，非空时保留双方。
- `chat.submit` 用固定请求 ID、消息 ID 和逻辑 executionId；附件准备期就占用会话，准备成功持久接收后才清对应版本的草稿。失败不创建空会话、不丢草稿。
- 重复提交不重复执行；已接收但尚未进入 checkpoint 的消息可恢复。启动不自动重放；显式恢复前检查 checkpoint，旧分支提交作废但原幂等回执保留。
- 任务等待审批不算成功，恢复更新同一记录；取消使旧审批失效。执行前建立记录，模型停用等依赖错误可追踪。同任务撞车记录 skipped，不排队、不补跑。
- 回放、等待、监控、自动修复共用取消信号；取消后无后续步骤、无自动修复版本写入。中断的审批可恢复，其他上次未结束运行标记中断。

### 正确的浏览器视图与局部容错

- 外部浏览器有独立只读工具栏、真实地址和连接状态；查看内置浏览器只改变显示。重试只恢复观察，撤回的目标不能重新取得控制权，动作不重放。
- 首次选择及恢复时同步授权标签页，选择成功立即同步观察对象；断线、画面失败及释放均明确显示暂停。
- 插件执行前及加载后重新检查启用、版本、页面和动作。停用后旧工具不能开始新动作；已派发动作可能仍在完成。
- 可选追踪关闭时不读密钥；解密失败只暂停对应集成并给出诊断，保留密文、清理旧环境变量，主窗口和普通聊天继续工作。

### 项目文件、模型与产物

- 项目文件可加入当前草稿；发送前核对项目目录并读取最新版，接收后保留内容快照和来源。只浏览或添加引用不读取正文加入模型上下文。
- 目录每页默认 100、最多 500，支持继续加载。文件名/路径搜索可取消，限制 200 条、20,000 项或 3 秒；不跟随符号链接，排除 `.git` 和 `node_modules`。
- 模型页支持持久搜索和状态筛选、厂商折叠、已启用优先和批量启停；批量原子提交，停用前显示受影响任务，保留任务原模型及正在运行的配置。
- Artifacts 按项目/会话/搜索/类型服务端筛选，默认 50、最多 200 条游标分页。列表不读正文；预览和导出按需加载。旧 `outputs.*` 与 `artifacts.list` 保持兼容。

### 确认中心与授权恢复

- 确认中心聚合工具审批和桌面许可，读取持久摘要索引，不逐个加载完整会话消息。
- 当前会话显示授权卡，其他会话经确认中心和通知提醒，不强制抢焦点。隐藏不等于拒绝，拒绝须显式操作。
- 默认本次任务授权，兼容单次和本对话授权；跨审批恢复保留任务授权，终止或取消清除，重启清空所有桌面授权。可查询与撤销，旧授权决定不可复活权限。
- 结构化区分用户接管、主动停止、撤销、权限不足和服务故障。设置显示未检测/检查中，聚焦或手动检查；仅授权返回阶段短暂轮询。
