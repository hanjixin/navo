# Computer Use 稳定性优化与验收

日期：2026-11-04。

## 本轮范围

完成评审中的第一轮稳定性修复：浏览器标签页撤回、对话独占、连接恢复与请求隔离；桌面窗口身份校验、用户输入接管；等待文本匹配。授权中心合并、授权范围选项与停止原因界面保留为后续体验优化。

## 实现

### 浏览器控制

- 撤回和取消调试横幅立即撤销授权，停止直播并使旧 driver 永久失效；等待连接或 attach 的旧操作在异步恢复后也不能继续发送。
- 重新授权使用新 driver；旧清理完成前新 attach 等待，旧 detach 不会误断开新的控制会话。
- 标签页由对话独占，显式切换、关闭和自动分配共用占用检查；一方结束不会断开另一方的控制。
- 会话结束释放租约，下一轮可重新获取原有、仍授权且空闲的标签页。撤回/占用不静默切换到其他页面，列表和切回内置浏览器仍可用于恢复。
- 请求和 CDP 事件绑定来源连接；旧响应、旧关闭回调不能影响重连后的请求。断线释放实际 debugger，挂起的 CDP 操作不会阻塞 detach，不自动重放已经提交的操作。
- handed/owned 更新串行并带授权代次；旧 handover 不能覆盖后来的 revoke，扩展创建页面的授权可跨 service worker 重启恢复。
- 列表请求有版本隔离，旧结果不会撤销刚创建的标签页；关闭事件可传播给已经撤回的旧 driver，数字 tab ID 重用不复活旧对象。
- 扩展安装同时比较 bundle 内容，确保相同版本号的修复也能更新；已有副本在离线更新后，下次连接只请求一次重载，首次安装不重载，失败不进入循环。其他非 Navo 目录继续受保护。

### 桌面控制

- AX 快照、截图及坐标下窗口返回窗口 ID、PID 和边界。所有输入携带观察时的 `expectedWindow`，原生层在实际注入前再次核对；同应用的另一个窗口也不能通过检查。
- 无法唯一确定窗口时可以读取，拒绝输入；坐标操作同时验证遮挡窗口。窗口变化或注入结果不确定后清空旧观察句柄，必须重新快照/截图。
- 普通键盘、鼠标按钮、滚轮和拖动触发暂停，保留原有 Esc、鼠标移动阈值及 Agent 事件标记过滤，用户事件继续传给系统。
- `desktop_wait_for` 在原始 AX 文本匹配并处理 CRLF，不再在 JSON 转义、预算裁剪后的显示文本里搜索。
- macOS/Windows 原生协议同步更新；手动 TextEdit smoke 脚本也携带窗口身份，确认新窗口后才输入。
